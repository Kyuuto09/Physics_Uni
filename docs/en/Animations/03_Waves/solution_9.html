Harmonic Oscillator

State: Underdamped
b²: 4 | 4mk: 800

About the Math

Equation:
m(d²x/dt²) + b(dx/dt) + kx = 0

Underdamped: b² < 4mk. The system oscillates back and forth.

Critically Damped: b² = 4mk. The fastest return to equilibrium without oscillating.

Overdamped: b² > 4mk. A sluggish, exponentially decaying return to 0.

Resolved using 4th-Order Runge-Kutta numerical integration (RK4).
