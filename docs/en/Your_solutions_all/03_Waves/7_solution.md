# Problem 7: Standing Wave Modes

### 1. Problem Statement

A standing wave with four antinodes is produced on a string of length $L = 80\text{ cm}$. What is the wavelength of this wave?

---

### 2. Solution and Explanation

**Concept Intuition:**
Think of a standing wave on a guitar string like fitting a specific number of "data packets" into a fixed-size buffer.
Because the string is tied down at both ends, the wave must start at $0$ (a node) and end at $0$ (a node).

An **antinode** is just the big vibrating "loop" or "bulge" between two nodes. Mathematically, exactly one loop equals exactly one-half of a full wavelength ($\frac{\lambda}{2}$).
If there are 4 antinodes, you have 4 half-wavelengths fitting perfectly onto the string. Two halves make a whole, which means the 80 cm string is holding exactly 2 full waves.

#### Step 1: The Harmonic Formula

The formula connecting the length of a fixed string ($L$), the number of antinodes/harmonics ($n$), and the wavelength ($\lambda$) is:
$$L = n \left(\frac{\lambda}{2}\right)$$

#### Step 2: Calculate the Wavelength

We are given the length ($L = 80\text{ cm}$) and the number of antinodes ($n = 4$). We plug these into our formula:
$$80 = 4 \left(\frac{\lambda}{2}\right)$$

Simplify the right side:
$$80 = 2\lambda$$

Solve for $\lambda$ by dividing both sides by 2:
$$\lambda = \frac{80}{2}$$
$$\lambda = 40\text{ cm}$$

_(If you need standard SI units, this is $0.4\text{ meters}$.)_

---

### 3. Final Answer

- **Wavelength ($\lambda$):** $40\text{ cm}$ (or $0.4\text{ m}$)
